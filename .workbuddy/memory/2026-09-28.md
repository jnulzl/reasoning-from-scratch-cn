### 踩过的坑（复用时别再踩）

1. `\ExplSyntaxOn` 与 `\makeatletter` 段之间 `@` 的 catcode 不同 → 带 `@` 的宏名会裂成两个宏，
   且 `\gdef\my@x{#1}` 会把 `#` 当普通字符而**不报错**。解法：跨段共享的宏名不带 `@`。
2. `titlesec` 必须同时定义带编号的章格式，numberless 才生效。
3. `\ifx` 不展开宏，判空用 `\ifx\macro\empty`。
4. `\fancyfoot` 里 `\raisebox` 会被页脚盒高度变化抵消，调不动基线；用绝对 overlay。
5. TikZ 键名 `line width` 的空格不能写成 `~`（pgfkeys 报 unknown key）。
6. `\fontsize{30}{32}` 第 2 参会被 `\linespread` 放大（实际行距 34.67bp）。
7. PyMuPDF 的 span bbox 是「字体全框」（约 1.18em）不是墨迹；量位置用 `origin`（基线），
   量字形用像素扫描。
8. 原书数字是**等高数字**，Georgia 是旧式数字（会降到基线以下）→ 换 Cambria
   （数字宽高比 0.496/0.671 em vs 原书 0.484/0.667 em，最接近）。

## 修复 TeX Live 2026 更新后全书代码块编译失败

用户升级 TeX Live 2026 并 `tlmgr update --self --all` 后，本书 465 个代码块全部编译失败：
`minted Error: Cannot locate file "book/content/main/main.listing" (kpsewhich failed)`。

根因（三件事叠加，缺一不复现）：
- `tcolorbox` 的 `tcblisting` 把代码写到 `\jobname.listing`（= `./main.listing`），再调 `\inputminted`；
- minted v3 的 `\minted@define@inputfilepath` 无条件给文件名加 `\import@path` 前缀；
- 章节用 `subfiles` 挂载，`subfiles` 依赖 `import`，把 `\import@path` 置为 `book/content/main/`。
→ 拼成不存在的 `book/content/main/main.listing`。

修法：`book/ccs.tex` 中在 `codebox`/`codeboxt` 定义之后给 `\minted@define@inputfilepath`
打 6 行补丁——优先按子文件目录解析，路径不存在时退回按输出目录解析。

同时修正：
- `book/content/main/03.tex` 7 处 `\textbackslashboxed` → `\textbackslash{}boxed`
  （`\textbackslash` 后直接跟字母会被 TeX 吞成一个控制字）。
- `ccs.tex` 注释与 README 中「正文字号 13pt」是错的，实际为 10pt（与原书实测一致），已改正。

结果：`xelatex -shell-escape` 连跑两遍，第二遍 **0 error**，产物 482 页 / 204 条书签 /
字体全部 Type0 内嵌 / 代码高亮正常。仅剩 102 Overfull + 196 Underfull（排版微溢出，非错误）。
